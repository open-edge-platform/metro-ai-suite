# Integrations

Guides for connecting VAP to a specific Video Management System (VMS), from setting up
the VMS through running an analytics application on its cameras.

- [Milestone XProtect Integration](./integrations/milestone/index.md) — Connect VAP to
  Milestone XProtect through Milestone AI Bridge, run Loitering Detection on XProtect
  cameras with overlays in Smart Client, and raise XProtect alarms from loitering events.

For Nx Witness, see the tutorials
[Loitering Detection with Nx Witness](./dls-vision-with-nx-witness.md) and
[Live Video Captioning with Nx Witness](./lvc-with-nx-witness.md).
