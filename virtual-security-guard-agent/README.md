# Virtual Security Guard Agent

**Virtual Security Guard (VSG) Agent** is an operator console for the **VSG agent**, an AI
security agent named **Argus** that runs on a Hermes agent server. The VSG agent searches
recorded and live camera footage through Intel's Video Search and Summarization (VSS)
application. The Hermes agent server cannot show video or images. The VSG console displays
the agent's results as match grids for human review, a floorplan route, live camera matches,
and PDF incident reports.

![VSG demo: the operator asks the VSG agent to find a worker who fell, confirms two matches from the warehouse camera, and the route appears on the floorplan](./docs/user-guide/_assets/vsg-demo.gif)
